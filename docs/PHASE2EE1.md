# Phase 2E-E1 — 原譜全画面練習と通し練習

実装と自動確認を行い、Chromebook + CASIO PX-100 + CME U2MIDI Proでの実機受入確認はユーザーが行います。Phase 3のリズム・テンポ評価、無音の時間判定、AIコーチは実装しません。

公開先: https://metaborin.github.io/ai-piano-practice/

## 使い方

「練習方法」で「できるまで」「通し練習」を選びます。右手・左手・両手とは独立しています。「通し練習」は、入力した演奏を順番に評価し、間違いも記録して次へ進みます。途中で練習方法を変更すると、指定していた開始位置の待機状態に戻ります。曲・手・開始小節・MIDI機器選択は維持します。

PDFまたは画像を登録した自分の曲で「元の楽譜」→「原譜で全画面練習」を押します。上部で小節・進捗・反復回数・練習方法・判定を確認できます。「練習・手本の操作」で手・方法・開始位置・練習開始・もう一度・手本の操作を開閉できます。「−」「倍率」「＋」で50〜200%に変更し、倍率ボタンで100%へ戻します。終了は「× 全画面終了」またはEscです。

PDFや画像そのものに現在位置や赤音符を重ねる機能はありません。正解データはMusicXMLです。「練習用楽譜」に戻ると現在の練習／手本位置にカーソルと表示範囲を合わせます。

## 練習方法と結果モデル

`PracticeMode = right | left | both` は既存のままです。新しく `PracticeFlowMode = until-correct | run-through` を追加し、PracticeSessionのsnapshotに保持します。初期値はuntil-correctです。

- until-correct: 既存MomentMatcherをそのまま使用。正解時に進み、不足・余分な音では待ちます。既存の300ms境界、同音連打、離鍵、赤表示を変更しません。
- run-through: 別のRunThroughMatcherで一つの入力試行を確定し、正誤にかかわらず1 PracticeTarget進みます。単音は最初の有効Note Onで即座に確定します。和音は入力音を集合にし、**最後の新しい音から100ms（CHORD_SETTLE_MS）**、または**最初の音から300ms（CHORD_MAX_WINDOW_MS）**の早い方で確定します。正解音がそろっていても、この短い確定待ちの間に来た余分な音を同じ試行へ含めます。
- 重複Note Onは既存のchannel/pitch単位の離鍵管理で抑制します。同じ和音試行に既に含まれる音を再入力しても音数を増やさず、settleを延長しません。次の試行に同音を使う場合は離鍵が必要です。
- タイマーの世代番号で古い通知を無効化します。リセット、もう一度、曲・手・開始位置・方法変更、入力リセット、手本開始、破棄時に未確定試行を取り消します。イベントループが遅延してタイマーより先に次入力が届いた場合も、期限切れを確定してから新しいTargetを参照します。
- フィードバックは直前に確定した試行を示します。通し練習の誤答は「○小節目：記録しました」と不足音・余分な音を表示します。次の試行が確定すると更新します。弾き直しは要求せず、OSMDへ不足音の赤表示を渡しません。

`PracticeAttemptResult` は次を保持するreadonly型です。

| フィールド | 内容 |
|---|---|
| sequenceOccurrenceId | 反復の各回を区別する演奏順上のID |
| sourceMomentId | 原本MusicXMLの同時刻位置ID |
| measureNumber | XMLの小節番号。既存モデルと同じstring型 |
| practiceMode / flowMode | 手の選択と練習方法 |
| expectedMidiNotes / playedMidiNotes | 正解音集合と実入力音集合 |
| matchedMidiNotes / missingMidiNotes / unexpectedMidiNotes | 一致、不足、余分な音 |
| result | correct / incorrect |
| startedAt / completedAt | performance.now()基準の受信・確定時刻（ms） |

結果はReact表示文字列ではなく `PracticeSession.getSnapshot().attempts` に残します。終了後も配列を保持し、手本開始・終了、原譜切り替え、全画面切り替えでは消しません。「もう一度」・新しい練習開始・曲／手／開始位置／方法変更では新しいセッションとして初期化します。今回は履歴の永続保存・クラウド送信はなく、再読み込みで結果は失われます。登録済みMusicXML・元PDF／画像のIndexedDB保存は従来どおりです。

終了時は「通し練習が終わりました」「正しく弾けた X / Y ステップ」「確認したい小節」を表示します。Yは開始位置から実際に演奏した試行数です。小節一覧は誤答の小節番号を重複排除し、反復の同じ小節をまとめます。詳細データでは各反復のoccurrence IDを区別します。

## 現時点の制限

無入力は試行にならず、無音のまま飛ばした音を検出・自動送りしません。入力を楽譜の順番に評価するため、音を丸ごと飛ばすと以後の入力と対象がずれる場合があります。リズム推定で補正しません。和音の間隔が100ms以上空くアルペジオや、前の和音から100ms未満で次の和音に入る演奏では、意図した和音の区切りと一致しない場合があります。これは時間グループ化の制限で、テンポ評価ではありません。

取り込める記譜の範囲はPhase 2E-Eと同じです。MusicXML→ScoreModel→PracticePlan/PracticeSequenceが練習・手本の唯一の音楽データです。PDFは参照表示だけで、OMR、PDFタップ移動、赤音符重畳、PDF上の同期位置は追加しません。

## 全画面の構成と状態維持

`useOriginalFullscreen` は表示専用です。`requestFullscreen()`をユーザー操作から呼び、未対応・例外・Promise拒否の場合でもCSSの固定配置でアプリ内全画面を利用できます。`fullscreenchange`でブラウザ側の退出を反映し、Escでも退出できます。保留中の要求には世代番号を付け、遅れて許可された要求でも終了操作を反映します。

Practice workspaceは同じDOM位置に置き、全画面時だけレイアウトを変えます。PracticeSession・DemoPlayer・ScoreView・OriginalScoreViewを全画面のために作り直しません。操作欄も非表示にするだけなので、手本の開始位置選択を失いません。画面外のUIをinertにし、終了後に元のフォーカスとbodyのスクロール設定を復元します。

全画面フックはMIDI・Practice・Demoを参照しません。全画面開始／終了のハンドラーにも、MIDIOutput.clear、All Notes Off、player.stop、session.resetはありません。曲・手・方法・開始位置変更や手動停止は、従来または今回の明示的なリセット操作として別途処理します。

元PDFは既存のPDF.jsビューを再利用します。複数ページ、表示範囲付近だけのcanvas描画、最大ピクセル数によるメモリ抑制を維持します。ズームは内容幅を変更し、ResizeObserverを通じて適切な解像度に描き直します。画像も同じ内容幅で拡縮します。全画面開始／終了ではBlobの再取得・ビューの再マウントをせず、同じ内部スクロールを保持します。縮小や画面サイズ変更で末尾が収まる場合はブラウザが有効な範囲にスクロール位置を丸めます。

練習用楽譜は原譜の裏で同じOSMDインスタンスを保持します。全画面原譜を使った後で「練習用楽譜」に戻ると、既存の明示的な現在位置への復帰要求を発行し、最新のPractice／Demoのmomentとoccurrenceからカーソルと表示範囲を復元します。ミニマップも再表示します。

## Chromebook実機確認

既存の登録曲・元PDFをそのまま使えます。Chromeで公開URLを再読み込みし、Phase 2E-E1表記を確認します。従来の接続でMIDI入力・出力を選び、テスト音がPX-100から鳴ることを確認してから進めてください。

1. マイム・マイムoriginal版と登録済み元PDFを選び、「できるまで」で練習開始。誤音・和音不足では同じ位置に留まり、正しく弾くと進むことを確認する。
2. 練習中に「元の楽譜」→「原譜で全画面練習」。直前の進捗・手の選択・開始小節・判定・MIDI機器選択が維持されることを確認する。
3. 全画面で正誤を入力し、上部の小節・進捗・できた／もう一度・足りない音／ちがう音が更新されることを確認する。
4. PDFを2ページ目までスクロールし、50〜200%のズームを試す。退出・再入場でも同じ付近を表示し、終了ボタンとEscの両方で退出できることを確認する。画像も同様に試す。
5. 「通し練習」に変更し、元の指定小節・手・曲・接続のまま待機へ戻ることを確認する。開始後、単音と和音をわざと間違え、停止せず1試行1ステップだけ進むことを確認する。
6. 元PDF全画面＋通し練習で数か所を間違えながら最後まで弾く。反復1回目→2回目の小節・進捗が正しく変わり、終了時の正答ステップ数と確認したい小節が演奏内容に合うか確認する。
7. 「もう一度」でセッション開始位置へ戻り、以前の結果が消えることを確認する。音を全く弾かずに待っただけでは進まないことも確認する。
8. 全画面の「練習・手本の操作」で、最初から／現在位置から／指定小節からの手本を聴く。表示中の曲がPX-100から鳴ることを確認する。
9. 手本が鳴っている間に全画面をON/OFFし、途中切れ・再発音・二重発音が起きず、元の練習結果が保たれることを確認する。停止と「すべての音を停止」も試す。
10. 原譜で練習・手本を進めてから練習用楽譜へ戻り、現在位置に緑帯と表示範囲が戻り、ミニマップが表示されることを確認する。
11. きらきら星へ戻し、従来の同音連打、間違いで待つ、終了・もう一度、MIDI機器選択、テスト音、手本停止が使えることを確認する。

音の継続・停止と100msの和音グループ化の弾き心地は実機での受入待ちです。自動テストではMIDI出力・clear回数・タイマー・再生位置を検証しますが、PX-100から実際に出る音の確認を代替しません。
